# Quick setup — if you’ve done this kind of thing before

[Set up in Desktop](https://desktop.github.com/) or

HTTPS: https://github.com/ilirium/big_file_sort.git

SSH: git@github.com:ilirium/big_file_sort.git

We recommend every repository include a [README](https://github.com/ilirium/big_file_sort/new/master?readme=1),
[LICENSE](https://github.com/ilirium/big_file_sort/new/master?filename=LICENSE.md), and
[.gitignore](https://github.com/ilirium/big_file_sort/new/master?filename=.gitignore).

# …or create a new repository on the command line

```bash
echo "# big_file_sort" >> README.md
git init
git add README.md
git commit -m "first commit"
git remote add origin https://github.com/ilirium/big_file_sort.git
git push -u origin master
```

# …or push an existing repository from the command line

```bash
git remote add origin https://github.com/ilirium/big_file_sort.git
git push -u origin master
```
